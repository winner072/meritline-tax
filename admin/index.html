This does not look like a GitHub access key. It should start with github_pat_.

Starts with github_pat_. You create it once on GitHub, then paste it here. Lost your key? Create a new one with the steps below.

If you leave this unticked, you paste the key again each time you open this page. Tick it only on your own computer: anyone who uses this browser could then publish to your website. The key is forgotten after 30 days without use, and when you sign out.

How to create your access key

Create my key on GitHub

  1. Sign in to GitHub with the account that owns the website.
  2. Open "Create my key on GitHub" above. If GitHub asks you to confirm your password or a code, do so. (Without the link: click your picture in the top-right corner, then Settings, then Developer settings at the bottom of the left menu, then Personal access tokens, then Fine-grained tokens, then Generate new token.)
  3. Token name: leave "Meritline blog admin".
  4. Expiration: leave one year. Put a reminder in your calendar a few days before it ends.
  5. Resource owner: make sure it shows your GitHub account.
  6. Repository access: choose "Only select repositories", then pick meritline-tax. Nothing else.
  7. Permissions: in the repository permissions, Contents must say "Read and write". If it is missing, add Contents and set it to Read and write. Metadata shows Read-only by itself. That is normal. Add nothing else.
  8. Click "Generate token" at the bottom, then copy the long code that starts with github_pat_. GitHub shows it only once. Save it in your password manager or another private place: you need it again each time you sign in.
  9. Come back here, paste it into Access key and click Sign in.
  10. Keep the key private. Never paste it into a post, an email or a website file. If someone may have seen it, delete it on the same GitHub page and create a new one.
  11. Use only this kind of key (fine-grained, starting with github_pat_). Older keys that start with ghp_ can change every repository on your account, so this page does not accept them.
